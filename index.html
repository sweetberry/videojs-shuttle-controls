videojs-shuttle-controls Demo

Shuttle / JKL Controls:

  • J : Shuttle backward (rewind at varying speeds)
  • K / Space : Toggle play / pause
  • L : Shuttle forward (fast forward at varying speeds)
  • ArrowLeft / ArrowRight : Step 1 frame backward / forward (hold Shift for 10x)
  • I : Set loop In-point
  • O : Set loop Out-point
